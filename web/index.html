What it does

Plans before it acts

An orchestrator spawns specialised sub-agents (researcher, coder, writer, verifier) and runs them in parallel where possible.

You pick the model

12 providers — Anthropic, OpenAI, Gemini, OpenRouter, Ollama, DeepSeek, Bedrock, Azure, xAI, Moonshot, and self-hosted (TGI / vLLM). Per role: orchestrator on Opus, summariser on Haiku.

Governed & access-controlled

RBAC, capability tokens, per-tool ACLs, consent gates, and a kill switch bound every action. In Enterprise mode an egress lock means even a successful prompt-injection can't move data out of your boundary; Agent Shield also screens every prompt, tool call, and output.

Budget is mandatory

Per-run dollar cap, wall-clock cap, tool-call cap. The kernel refuses to bust the budget. No surprise $200 bills.

Self-host & air-gap

Runs entirely in your environment — laptop, VPC, Kubernetes, or a disconnected network with no required data egress. Reachable across 12 channels (Telegram, Discord, Slack, Signal, Email, Matrix, Bluesky, Mastodon, Voice + WhatsApp, SMS, iMessage).

Audit-ready & compliant

Signed, hash-chained, append-only audit log with SIEM export, encryption-at-rest, and DSAR — SOC2-aligned evidence built to survive a security review. No telemetry; your data never leaves your environment.

Install

git clone https://github.com/Daybreak-AI-Labs/Law_Firm && cd Maverick
git checkout --detach <reviewed-full-40-character-commit-sha>
pip install -e ./packages/maverick-core -e ./apps/installer-cli
maverick init

Install from a reviewed source commit. The Maverick distribution names are not yet reserved on public PyPI, so public-index installation is disabled until those namespaces are secured. Requires Python 3.10+.

Who it's for

Security & compliance teams

Self-host on your own infrastructure with governance on by default: RBAC, capability scoping, a tamper-evident audit trail, encryption-at-rest, and SIEM export.

  • Deployable air-gapped — no required data egress
  • Signed, verifiable audit log for review
  • SOC2-aligned evidence + DSAR built in

Engineers + power users

Advanced mode exposes every knob: per-role model assignment, custom MCP servers, plugin allowlist, per-tool rate limits, retention, persona, notifications, full sandbox + channel matrix.

  • Plugin SDK with maverick plugin new
  • Programmatic REST API at /api/v1
  • MCP server in both directions
