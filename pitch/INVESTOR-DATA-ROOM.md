# Lightwork — Investor Data Room Checklist

> A pre-revenue deep-tech seed doesn't need a 200-document data room. It needs a
> **tight, honest, fast-to-read** one that lets a partner get to conviction in a
> week. Build the **Tier-1** set first (it's most of a "yes"); have **Tier-2**
> ready for diligence; skip the rest until asked.
>
> **Status key:** ✅ you have it · ◑ partial / needs polish · ⬜ to build · ✱ founder-only input

## Tier 3 — only if asked

- Customer references / design-partner intros · detailed unit economics ·
  hiring pipeline / key hires · prior board/advisor decks · press / analyst
  coverage · detailed security audit reports (you don't have these yet — say so).

## How to run the room (mechanics)

- **Tooling:** a single shared **Google Drive / Notion** folder, or **DocSend**
  (gives you per-viewer analytics — who read the deck, for how long, where they
  dropped). Gate access; don't email a public link.
- **Sequence:** Teaser email → (if interest) Deck → (after a call) Data-room
  link. Don't lead with the full room.
- **One narrative, three depths:** the same story in a 30-sec line, a 3-min
  demo, and a 1-week diligence read. Everything above should reinforce one
  thesis: *the governed, provably-improving agent workforce for regulated work.*
- **Honesty as an asset:** you're pre-revenue and alpha — say it plainly. Your
  edge is a built, defensible asset + an honest proof culture (the proof pack
  literally refuses to fabricate a number). Lean into it; don't pad traction.

## The shortlist of gaps to close (in order)

1. **Founder why-us** (item 4) — 30 minutes of writing; biggest leverage.
2. **The ask + use of funds** (item 3) — decide the number and the milestones.
3. **Demand evidence** (item 8) — run the outreach; even a few real conversations.
4. **Cap table + incorporation + IP** (items 9–11) — table stakes for diligence.
5. **Simple financial model** (item 12).
