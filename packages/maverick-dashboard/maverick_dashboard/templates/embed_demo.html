Embedded analytics

Put a live snapshot of your workspace — spend, activity, and outcomes — on any internal page, like a team wiki or status hub.

This is the analytics card, running live against this workspace. It shows total spend, the cost trend, and work by status, and it updates every time the page loads:

Add it to another page

Copy the snippet below into the page where you want the card to appear. Replace YOUR-DASHBOARD with this dashboard's address, and ask your administrator for an access token if your workspace requires sign-in: 

<script src="http://YOUR-DASHBOARD:8765/static/lightwork-analytics.js"></script>
<lightwork-analytics
    endpoint="http://YOUR-DASHBOARD:8765"
    token="YOUR-ACCESS-TOKEN"></lightwork-analytics>

Good to know

  • Works on pages served alongside Bjerken and Day. For security, browsers only let the card load data from pages on the same address as this dashboard (or behind the same reverse proxy). A page hosted elsewhere will show a blocked-request error rather than your data.
  • Treat the token like a password. Anyone who can view the embedding page can see the token, and it grants the same access as the dashboard itself. Only embed on pages whose audience you trust with that access. If your workspace runs without sign-in, leave the token out entirely.
  • View-only. The card only reads data — it can't change anything, and it shows the error plainly if a request fails.
  • Already embedded somewhere? Snippets created before the Bjerken and Day rebrand (<maverick-analytics>) keep working unchanged.
