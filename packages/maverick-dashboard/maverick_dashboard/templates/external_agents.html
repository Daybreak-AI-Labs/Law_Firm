Connect your platform

  1. Enroll the agent below (its ceilings are the contract).
  2. Mint its rest credential — shown once, store it in your platform's secret manager (Salesforce Named Credential, AWS Secrets Manager).
  3. Point your platform at the gateway: import the gateway description as an Agentforce External Service or a Bedrock action group, and have the agent call screen before consequential actions and runs when work completes.
