How to make it work

  1. Pick a service below — Slack, Telegram, Discord, WhatsApp, SMS or email — and tick Enabled.
  2. Paste the credentials that service issues (bot tokens, mail server details, and so on) into its fields. They're stored securely and never shown again — leaving a field blank keeps what's already saved.
  3. Press Save. The change takes effect the next time the channel service starts. If a channel isn't responding, ask your administrator to check that the channel service is running.
  4. Message the agent from that service. Requests run through the same governed workforce as goals started here, and replies come back in the same conversation.
